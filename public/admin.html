Quick start: use a standard course

For point to point, "wind from" is just the direction from start to finish.

Marks, in sailing order

The first item is the start and the last item is the finish. Drag marks on the map to move them.

    Every ship's AIS transponder has a 9-digit MMSI number. Look a ship up by name on MarineTraffic or VesselFinder to find it.

    Tracking period

    Ship positions are only collected between these times, for example from the day before the start until a few days after. Tracks from before this period are removed.

    A ship counts as having rounded a mark once its track passes this close to it, or crosses a line. 0.15 nm is about 280 m.

    Test with simulated ships

    Want to see how it works before the race? On GitHub, open Actions → Collect ship positions, click Run workflow, tick the test box and run it. For the next 15 minutes the public page shows made-up ships sailing the course in use.
